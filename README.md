# AgenticAI_with_Java
Welcome to my Agentic AI with Java learning journey!

I am exploring and building my knowledge of Generative AI and Agentic AI using Java. This repository contains my learning notes, code examples, experiments, and hands-on implementations of different AI concepts and frameworks.

🎯 Learning Objectives

Understand Generative AI and Agentic AI concepts.

Learn how AI agents work and how they make decisions.

Explore Model Context Protocol (MCP) and its integration with Java.

Understand Retrieval-Augmented Generation (RAG).

Integrate Large Language Models (LLMs) into Java applications.

Build AI-powered applications using popular Java frameworks.

🛠️ Technologies & Frameworks

Java – Core programming language.

OpenAI Java SDK – Integrating OpenAI models into Java applications.

Spring AI – Building AI-powered applications using Spring Boot.

LangChain4j – Developing LLM-powered applications and AI agents.

MCP (Model Context Protocol) – Connecting AI applications with external tools and data sources.

RAG (Retrieval-Augmented Generation) – Building applications that retrieve relevant information to generate context-aware responses.
